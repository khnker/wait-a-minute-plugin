# Design Tokens (Req-25)

## Spacing Scale
- `0`: 0px
- `1`: 4px
- `2`: 8px
- `3`: 12px
- `4`: 16px
- `6`: 24px
- `8`: 32px
- `12`: 48px
- `16`: 64px

## Typography Scale
- `xs`: 12px / Line height: 16px
- `sm`: 14px / Line height: 20px
- `base`: 16px / Line height: 24px
- `lg`: 18px / Line height: 28px
- `xl`: 20px / Line height: 28px
- `2xl`: 24px / Line height: 32px
- `3xl`: 30px / Line height: 36px

## Semantic Colors
- `primary`: Main brand/action color.
- `secondary`: Supporting interface color.
- `background`: Page base.
- `surface`: Card/elevated elements.
- `text-primary`: High-contrast body text.
- `text-secondary`: Low-contrast auxiliary text.
- `danger`: Error states.
- `warning`: Cautionary alerts.
- `success`: Positive outcomes.
