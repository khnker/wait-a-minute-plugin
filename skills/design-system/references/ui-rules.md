# UI Rules (Req-24)

## 1. Layout & Composition
- **Rhythm**: Use an 8pt grid for layout and 4pt for components.
- **Hierarchy**: Distinct visual weight for Primary vs Secondary actions.
- **Density**: Prefer generous whitespace unless for data-heavy dashboards.

## 2. Interaction
- **Feedback**: Immediate visual state change on interaction (hover, active, focus).
- **Affordance**: Elements must look like they can be interacted with.

## 3. Accessibility
- **Contrast**: Minimum WCAG AA compliance (4.5:1 for normal text).
- **Focus**: Visible focus indicators for keyboard navigation.
