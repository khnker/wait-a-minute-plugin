# Tastemaker

## Definition
Tastemaker is the curatorial layer that ensures the UI isn't just "correct" (functional/accessible) but "refined" (high taste/premium feel).

## Taste Profiles
- **Minimalist**: Max whitespace, monochromatic with 1 accent, extreme typographic hierarchy.
- **Enterprise**: Compact density, high utility, strict alignment, neutral palette.
- **Playful**: Bold colors, softer radii, micro-animations, asymmetrical elements.

## Application Process
1. **Profile Selection**: Identify the desired taste profile for the project.
2. **Audit**: Review current UI against profile characteristics.
3. **Refine**: Adjust tokens (spacing, radii, color contrast) to align with the profile.
