# Design for Production Hardening

- Audit query builder: Pure function to filter audit logs.
- Budget enforcer: Prune items based on budget constraints.
- Replay engine: Deterministic event replay.
- Hook validator: Validate hook definition.
- Skill registry: Skill registry with lookup, deps, version check.
- Tool interceptor: Intercept tool calls.
- Error recovery: Retry/fallback/circuit breaker logic.
