# Change: wam-context-sufficiency-contract

## Problema

La suficiencia actual se basa principalmente en keywords.

Esto confunde:

"existe contexto relacionado"

con:

"existe contexto suficiente para ejecutar".

## Propuesta

Definir un Context Sufficiency Contract derivado de la tarea.

El contrato identifica condiciones que deben estar disponibles antes
de permitir ejecución autónoma.

## Categorías

- required project knowledge;
- required decision;
- required constraint;
- required dependency;
- required verification knowledge;
- unresolved critical unknown.

## Objetivo

Sufficiency debe representar capacidad de ejecución segura,
no solamente overlap textual.
